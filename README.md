# Summa-Dealership
**Stappen om het project te installeren:**

1: git clone https://github.com/BoboAero/Summa-Dealership.git
  
2: Navigeer naar de juiste map (summa_dealership) 

3: composer install

4: npm install

5: cp .env.example .env 

6: Verander DB_CONNECTION=mysql naar 'sqlite'

7: php artisan key:generate

8: php artisan migrate:fresh



**Project opstarten:**

1: npm run dev

2: php artisan serve
